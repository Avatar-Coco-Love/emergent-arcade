# Emergent Arcade for teachers

Every game here is a small working system: a few simple rules that add up to
behavior nobody wrote down directly. That makes them useful for talking about
systems, feedback loops and design, in science, computing or design classes.

Play: https://avatar-coco-love.github.io/emergent-arcade/

## Practical details

- **Free, no accounts, no installs.** A browser on a phone, tablet, Chromebook
  or PC is enough. Nothing to sign up for.
- **Offline copies.** Open a game and choose "Download a copy". You get one
  HTML file that runs offline in any browser, with no network access at all,
  so it works on a locked-down school network or a computer with no internet.

## Privacy

- **Anonymous play stats.** To tune the games, the arcade records time played,
  wins and losses, scores and achievements. No accounts, no cookies, no names
  unless a player types one. Turn it off per browser in Settings (the gear
  icon), or use the offline copies, which send nothing.
- **Leaderboards are public.** They show a made-up name like "Amber Otter"
  unless a player types their own, and anyone can see it. Ask students to keep
  the made-up name or use a nickname, never their real name.
- **Progress stays in the browser.** Bests and achievements are saved on the
  device, not on a server. Settings can export, import or erase them.
