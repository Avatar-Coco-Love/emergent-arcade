# Lights Out over GF(2) (idea, not built)

Category: generated puzzle, linear algebra. Rank: **hold** (see
`puzzle-ideas.md`). Status: proposed, not yet approved.

- **Premise:** the classic toggle grid, generated by random presses so it is
  always solvable.
- **Verbs:** *press*, *pin* (mark a cell as don't-touch), *echo* (replay the
  last press elsewhere).
- **Why it works:** tiny, and the bot is trivial.
- **Weakness:** the weakest on "engaging" because the puzzle is well known.
  Better as a mode inside another game than as a standalone one.
