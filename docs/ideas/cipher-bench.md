# Cipher Bench (idea, not built)

Category: generated puzzle, cryptanalysis and language statistics. Rank:
**second** (see `puzzle-ideas.md`). Status: proposed, not yet approved.

- **Premise:** a substitution-cipher sentence, with a letter-frequency
  histogram next to it.
- **Verbs:** *assign* a letter, *probe* (spend a token to reveal a letter's
  position pattern), *lock* (freeze a confident letter so it can't be
  disturbed).
- **Why it works:** frequency analysis is the real technique. Players learn
  that E and T are common without being told. It is the only candidate that
  teaches language rather than math, and it opens a new subject area.
- **Cost:** needs a bundled quote or word list, so the file is bigger. A few
  hundred short quotes is still small. The "primitives only" rule is about
  art and audio, so text should be fine.
